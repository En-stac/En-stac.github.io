# 在线工具箱（零成本盈利项目）

纯静态网站，7 个高频搜索工具，专为搜索引擎流量和广告变现设计。

## 一、上线（免费，约 10 分钟）
1. 注册 GitHub 账号（github.com）
2. 新建仓库，名字取 `你的用户名.github.io`（可得到免费网址）
3. 把本文件夹里所有文件上传到仓库（网页上直接 Add file → Upload files）
4. 等 1~2 分钟，访问 `https://你的用户名.github.io` 即已上线

## 二、让搜索引擎收录（免费）
1. 打开 search.google.com/search-console，添加你的网址
2. 在"站点地图"里提交 `https://你的用户名.github.io/sitemap.xml`
   （先打开 sitemap.xml 把里面的域名替换成你的实际网址）
3. 百度同理：ziyuan.baidu.com 提交链接

## 三、接入广告赚钱
1. 网站上线且有内容后，申请 adsense.google.com（需年满18岁）
2. 审核通过后，把每个页面里的 `<div class="ad-slot">广告位...</div>` 替换为 AdSense 给的广告代码
3. 收入与访问量成正比，一般每千次浏览几元到几十元

## 四、后续增长（都可以找我继续做）
- 增加更多工具 = 更多搜索流量入口（图片压缩、日期计算、汇率换算等）
- 每个页面已写好 SEO 文案，持续补充内容有利于排名
- 可绑自定义域名（约 ¥60/年）提升可信度

## 重要说明
- 所有计算都在浏览器本地完成，无隐私风险，这也是审核加分项
- 广告收入不会立竿见影，通常需要 1~3 个月搜索引擎收录和排名积累
